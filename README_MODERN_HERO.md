## 🚀 Quick Start (3 Steps)

### Step 1: Link CSS
Add to `Home.aspx` `<head>` section:
```html
<link rel="stylesheet" href="CSS/modern-hero.css" />
```

### Step 2: Replace Hero HTML
Replace your current hero section (lines ~39-230) with content from `modern-hero-section.html`

### Step 3: Add JavaScript
Add before closing `</asp:Content>`:
```html
<script src="JS/modern-hero.js"></script>
```

**That's it!** Your modern hero section is live! 🎉

## 🔧 Customization Guide

### Change Background Image
File: `modern-hero-section.html`, line 10
```html
style="background-image: url('YOUR-IMAGE-HERE');"
```

### Adjust Parallax Speed
File: `JS/modern-hero.js`, line 15
```javascript
const parallaxSpeed = 0.5; // 0.3 = slower, 0.7 = faster
```

### Modify Highlight Color
File: `CSS/modern-hero.css`, line 191
```css
.hero-highlight-word {
    color: #FFB800; /* Your brand color */
}
```

### Add More Destinations
File: `modern-hero-section.html`, inside dropdown
```html
<div class="dropdown-item" data-value="Paris, France">
    <i class="fa-solid fa-tower-observation"></i>
    <div>
        <div class="dropdown-item-title">Paris, France</div>
        <div class="dropdown-item-subtitle">Romantic Getaway</div>
    </div>
</div>
```

### Integrate Date Picker (Flatpickr)
Add to `Home.aspx`:
```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/flatpickr/dist/flatpickr.min.css">
<script src="https://cdn.jsdelivr.net/npm/flatpickr"></script>
<script>
flatpickr("#modern-date-input", {
    mode: "range",
    minDate: "today",
    dateFormat: "M d, Y"
});
</script>
```
