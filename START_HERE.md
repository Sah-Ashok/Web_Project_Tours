- Copy entire content


## 🛠️ Customization Quick Reference

### Change Background Image
**File**: `modern-hero-section.html`, line 10
```html
style="background-image: url('YOUR-IMAGE-URL');"
```

### Adjust Parallax Speed
**File**: `JS/modern-hero.js`, line 15
```javascript
const parallaxSpeed = 0.5; // Try 0.3-0.7
```

### Modify Highlight Color
**File**: `CSS/modern-hero.css`, line 191
```css
.hero-highlight-word {
    color: #FFB800; /* Your brand color */
}
```

### Add Date Picker
**Add to Head**:
```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/flatpickr/dist/flatpickr.min.css">
<script src="https://cdn.jsdelivr.net/npm/flatpickr"></script>
```

**Add to JavaScript**:
```javascript
flatpickr("#modern-date-input", {
    mode: "range",
    minDate: "today"
});
```
